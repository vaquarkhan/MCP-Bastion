# Roadmap (high level)

This file highlights **directions** the community and maintainers may work toward. It is not a commitment schedule; track execution in GitHub **Issues** and **Milestones**.

| Theme | Examples of work |
|--------|-------------------|
| **Adoption & docs** | More `examples/`, translated snippets, video walkthroughs linked from README. |
| **Integrations** | Additional `mcp-bastion-*` provider packages; TypeScript parity where demand is highest. |
| **Enterprise patterns** | Reference architectures (GitOps + `bastion.yaml`, SIEM field notes) in [SECURITY_OBSERVABILITY.md](SECURITY_OBSERVABILITY.md). |
| **Quality** | Broader harness coverage, performance budgets per release. |

Ideas welcome via **Issues** (tag **`good first issue`** when appropriate) or **Discussions**.
