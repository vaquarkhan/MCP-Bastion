## GitHub issues

Open an issue for **bugs**, **feature requests**, or **documentation gaps**:

https://github.com/vaquarkhan/MCP-Bastion/issues

Include when possible:

- MCP-Bastion version (`mcp-bastion --version` or PyPI pin)
- Relevant `bastion.yaml` snippet (redact secrets)
- Expected vs actual behavior
- Minimal reproduction steps

Label **`good first issue`** tasks are suitable for new contributors — see [CONTRIBUTING.md](CONTRIBUTING.md).

## Security vulnerabilities

**Do not** open a public issue for security bugs.

Use [GitHub Private Security Advisories](https://github.com/vaquarkhan/MCP-Bastion/security/advisories/new) or follow [SECURITY.md](SECURITY.md).
